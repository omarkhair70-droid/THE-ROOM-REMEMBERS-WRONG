# THE ROOM REMEMBERS WRONG

**Interactive installation / 2026**

A room notices a visitor, holds a temporary trace of them, and then remembers them incorrectly.

The work asks a simple question:

> If a machine keeps everything about you, is it remembering you — or only storing you?

## Artistic rule

This is not a camera effect and not a surveillance demo.

The system should:
- sense presence without identifying a person;
- turn movement and stillness into a temporary visual body;
- keep only abstract traces, never a stable portrait;
- allow memory to decay, drift, merge, and misremember;
- let later visitors inherit fragments of earlier encounters.

## V0 — live laptop prototype

The first prototype runs in a browser with:
- laptop webcam;
- real-time canvas rendering;
- motion / presence sensing;
- short-term afterimages;
- imperfect memory drift;
- decay after the visitor leaves.

The projector is only an output surface. Once V0 feels alive on the laptop, the same output will be projected into a dark room at the college.

## Installation target

A small dark room or corridor:
- 1 projector
- 1 laptop
- 1 webcam / camera
- optional speaker
- matte wall or projection surface
- controlled light

The final installation has no start button, score, account, or identity capture.

## Development milestones

1. **V0 — Presence / Afterimage**  
   Webcam → movement → delayed traces → decay.

2. **V1 — Body Memory**  
   Separate the body from the background and store abstract body states.

3. **V2 — Misremembering Engine**  
   Drift, omission, recombination, temporal mistakes, inherited traces.

4. **V3 — Installation Test**  
   Projector + dark room + real visitors.

5. **V4 — Exhibition / ONX package**  
   Refine sound, pacing, documentation, production plan and application material.

## Privacy law of the work

No face recognition.  
No names.  
No cloud identity.  
No permanent video archive.

The artwork should remember less than the camera can see.

— Omar Khair, 2026
