# V0 TEST — PRESENCE / AFTERIMAGE

## What this test is for

V0 is not judged by whether the graphics look impressive.

It passes only if a visitor can feel this sequence without explanation:

1. **The room notices me.**
2. **Something of me stays behind.**
3. **That thing is no longer exactly me.**
4. **When I leave, the room keeps losing me.**

## Laptop test

1. Run:
   ```bash
   npm install
   npm run dev
   ```
2. Open the local URL in Chrome.
3. Click **ENTER** and allow camera access.
4. Stand 1.5–3 m from the camera.
5. Move one arm, stop, step sideways, then leave frame.
6. Watch what remains.

## First college projector test

Use:
- one dark or dim room;
- one matte wall;
- one projector;
- laptop webcam at roughly chest / head height;
- laptop hidden to the side if possible.

Do not add decoration yet.

### Test with 10 visitors

Ask nothing before they enter.

After they leave, ask only:
- What did you think the room was doing?
- At what moment did it stop feeling like a mirror?
- Did anything feel like it belonged to someone before you?
- Did you want to stay, move, or leave? Why?

Do not explain the concept until after their answers.

## Failure conditions

V0 fails if most visitors describe it only as:
- webcam filter;
- glitch effect;
- motion trail;
- screensaver.

If that happens, do not add more visual effects. Change the memory behaviour.
